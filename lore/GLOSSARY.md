# Glossary

| Term | Usage |
| --- | --- |
| **Project Tango Charlie (PTC)** | The project and fictional universe. Use the full name on first reference. |
| **The Return to Earth** | The narrative title beneath Project Tango Charlie. |
| **The PTC Chronicles** | The literary record and the name of the planned companion website and digital book. [Chronicles](chronicles/README.md) |
| **Commander Kara Voss** | The first canonical character and commander dispatched to Earth. [Character reference](characters/kara_voss.md) |
| **TC167** | The designation of Kara Voss's assigned fighter. [Technology reference](technology/tc167.md) |
| **Terrestrial Navigation Helmet** | Kara’s flight helmet with an independent terrestrial navigation HUD and a rechargeable micro protonic battery. [Equipment reference](technology/terrestrial_navigation_helmet.md) |
| **Intergalactic war** | The catastrophic conflict involving humanity before the exodus. This is a descriptive term. [History](history/intergalactic_war.md) |
| **Human exodus** | Humanity's departure from Earth and dispersal into space. [History](history/human_exodus.md) |
| **Return expedition** | The unnamed colony's deep-space journey toward Earth to investigate possible human survival there. [Colonies](colonies/README.md) |
| **Unexplained signal** | A mystery associated with Kara's return. Its source and meaning remain open. [Mysteries](MYSTERIES.md) |
| **Utility Jeep** | Ground transportation available at the outlying service compound. Kara learns its location through exploration. [Jeep](technology/jeep.md) |
| **Maintenance hangar** | The large airbase building Kara sees after leaving TC167. [Airport](locations/abandoned_airport.md) |
| **Outlying service compound** | A facility near the crash site and apart from the airport. [Compound](locations/outlying_service_compound.md) |
| **Heavy recovery hangar** | The airport hangar housing a stationary crane and a towable trolley. [Hangar](locations/heavy_recovery_hangar.md) |
| **Recovery trolley** | Aircraft recovery equipment available somewhere within the airbase. [Initial world state](world/initial_world_state.md) |
| **Restoration** | The effort to bring Earth back to a condition capable of sustaining life and civilization. Its feasibility remains unresolved. [Earth](locations/earth.md) |
