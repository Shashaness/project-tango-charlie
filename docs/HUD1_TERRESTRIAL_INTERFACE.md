# Terrestrial interface

The navigation HUD shows position and heading. The lower-left helmet panel uses **F7** to cycle General, Quests, and Log. Use **Page Up** and **Page Down** when a panel spans multiple pages. **I** opens Kara's journal, **N** advances it, and **U** requests a hint.

Press **O** to select a nearby object and show its name, position in the list, known state, and current action. Press **T** for the action shown. Use **Shift+T** to inspect the object, or **T** when Inspect is already the action. Inspection cards show the result provided by the interaction system.

Selection and interaction results hold for three seconds. Inspection results hold for five seconds. Each uses the same fade and upper-left card. Cycling replaces the card immediately and creates no Log entry. General continues to show the current controls and the selected object's inspection result for the session. The Log retains recent interaction feedback.

Quest and objective completions appear independently beneath the compass. When space is tight, the contextual card stacks below an active completion banner. General retains the full feedback if the upper card has room for only part of it.
